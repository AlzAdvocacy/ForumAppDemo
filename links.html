Demo links
Alz Advocacy Forum app prototype. Every name and meeting is fictional.

Hand someone a persona

Each link opens the app as one fictional attendee. Point a phone camera at the code, or copy the link into a text message.

Set up a demo phone

  1. iPhone: open a persona link in Safari, tap Share, then Add to Home Screen, then Add. Open the app from the Home Screen. If it opens to the code screen, type the persona's code once and it stays signed in.
  2. Android: open the link in Chrome and tap Install when it appears, or use the menu and choose Add to Home screen.
  3. Open the app once while you have a signal. After that it opens without one.

Run the demo

  • Demo controls: tap the AIM logo at the top of the app three times. Tap Done to hide them.
  • Jump to Hill Day morning sets the clock so countdowns and "up next" make sense. "Hill Day at the real time" matches the phone's own clock.
  • Schedule change in 10 seconds gives you time to set the phone down. The banner appears, the phone buzzes on Android, and the change shows on Home and Meetings.
  • Airplane mode keeps the whole schedule on screen and shows the offline banner. Turn it off and the app says it is back online.
  • Reset demo data in the controls puts everything back to the start.
